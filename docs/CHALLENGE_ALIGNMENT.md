# Challenge alignment

The supplied 2026 MODIS–VIIRS hot spots brief defines the objectives used here. The [challenge page](https://www.spaceappschallenge.org/2026/challenges/modis-and-viirs-hot-spots/) returned HTTP 502 during verification. Direct product documentation and archive metadata underpin the methods. IGNIS is an independent local project.

| Objective in the supplied brief | Lahore and California implementation |
|---|---|
| Build a long historical burning-activity calendar | Full supplied positive record from November 2000 into November 2026, UTC day inspection, month-by-year navigation and a 2012 instrument transition marker. |
| Harmonize MODIS and VIIRS | Stable common grid, independent quality rules, explicit shared and sensor-only occupancy, candidate index eligibility evaluated per study rectangle. |
| Examine patterns and unusual periods | Recorded monthly peaks by year, seasonal sums and comparisons with records from the same calendar month. Formal anomaly ranks require documented coverage. |
| Relate the calendar to geography | Linked Leaflet points, source details, offline geographic context, optional OSM tiles and observed-point envelope. |
| Support decision-makers and reproducibility | Scoped exports, real-data reconciliation, source manifest with ZIP hashes, scientific notes, desktop and mobile journeys. |

The published analytics cover the two parent study rectangles. Custom AOIs would require additional unsampled spatial partitions, including raw observation totals and boundary handling. Local retained cell tables are available for scientific follow-up. No service, API key or forecast model is required.
